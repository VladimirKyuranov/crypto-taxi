THE CRYPTO TAXI - referral landing page (static build)

This folder is ready to publish on GitHub Pages exactly as it is.

HOW TO PUBLISH
1. Create a repository on GitHub (or use an existing one).
2. Upload everything INSIDE this folder to the repository root.
   index.html must sit at the root, with the assets/ folder next to it.
3. In the repository: Settings -> Pages -> Source: "Deploy from a branch",
   Branch: main, Folder: / (root). Save.
4. Wait about a minute, then open https://<your-username>.github.io/<repo-name>/

NOTES
- All asset paths are relative, so the page works at yoursite.github.io/repo/
  and on a custom domain without changes.
- Single page, no build step and no server needed: just these files.
- Every sign-up / play button goes to:
  https://thecryptotaxi.com/register?ref=XD8KHS8N
- Footer Telegram links point to the game's official channels.
